# 测试与演示复现

在项目根目录执行。数据库、批次记录、模型输出、账号会话与报告均为本地产物，不属于仓库内容。

## 离线测试

`python -m pytest -q` 覆盖工作流分支、政策规则、补充信息、审核、角色与客户隔离、会话失效、后台排队、重试、租约接管和幂等。测试创建隔离目录与临时凭据，不依赖预置账号，不请求模型服务。

## 合成批次

停止服务后执行 `python scripts/seed_demo.py`，再启动工作台查看结果。默认复用已有批次，`--new` 额外创建 200 条工单。通过持久化队列执行工单与模拟审批，校验失败任务、工单总数与模型用量；批次固定离线模式。报告 `docs/batch-200.json` 仅保存在本地。

## 标注评估

`python evaluate.py` 使用 24 条合成标注样本离线评估，输出到 `data/evaluation.json`。`--live` 调用真实模型并消耗额度，建议添加 `--output data/evaluation-live.json`。指标定义随报告输出，不应把离线规则表现解释为真实模型准确率。

## 真实模型完整流程

配置 `.env` 的 live 模式、有效模型名与密钥，再执行 `python scripts/verify_live.py`。工具创建独立工作空间与随机临时管理员，经过 HTTP 接口、认证、后台任务、模型、人工审核与模拟业务执行进行检查，包含重启恢复和重复审批。报告为本地 `docs/live-verification.json`。

真实请求受网络、模型权限、限额与模型行为影响。小样本验收不是生产业务评测；报告不随代码发布。

## 验证范围

已验证平台为 Windows 与 Python 3.14。测试针对本地单进程应用，不覆盖多实例竞争、断电损坏、真实交易或生产负载。SQLite 事务和租约测试不等于分布式队列可靠性验证。
